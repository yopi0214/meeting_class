# 결과물 예시

`practice-start/`의 가상 자료로 명령을 실행했을 때 나온 결과입니다. 자료와 결과는 모두 가상입니다. 파일을 내려받아 Word, PowerPoint로 열어 보세요. 미리보기 그림은 [`preview/`](preview)에 있습니다.

| 명령 | 입력 | 결과 파일 |
|---|---|---|
| `/intake` | `inbox/`의 새 자료 3개 | [`intake_sources.md`](intake_sources.md) (출처 기록 한 건) |
| `/weekly 2026-11-16` | 지난 기록(11-09)과 새 자료 | [`weekly_2026-11-16.docx`](weekly_2026-11-16.docx) |
| `/meeting-prep 교수미팅 2026-11-17` | 지난 미팅(11-10) 이후의 기록 | [`meeting-prep_2026-11-17.docx`](meeting-prep_2026-11-17.docx) |
| `/progress-ppt 교수미팅 2026-11-17` | 지난 발표 PPT(11-10)와 새 자료 | [`progress-ppt_2026-11-17.pptx`](progress-ppt_2026-11-17.pptx) |
| `/meeting-close 2026-11-17_교수미팅` | 학생이 Word에 쓴 미팅 메모 | [`meeting-close_2026-11-17.docx`](meeting-close_2026-11-17.docx) |

## 참고

- `weekly`와 `meeting-prep`은 문서 분량 규칙(2쪽 이내)을 적용해 다시 만든 결과입니다.
- `progress-ppt`와 `meeting-close`는 분량 규칙을 넣기 전에 만든 결과입니다.
- 모든 문서의 첫 문단에 `예시 — 실습용 가상 자료입니다.`가 들어 있습니다.
