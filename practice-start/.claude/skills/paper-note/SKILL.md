# /paper-note — 논문 읽기 노트

대상: `$ARGUMENTS`

## 순서

1. **읽기:** PDF가 길면 나눠서 읽는다. URL이면 페이지를 읽고, 전문을 볼 수 없으면(유료 등) 초록만 읽었다고 노트에 적는다.
2. **서지 정보:** 저자, 연도, 제목, 학술지, DOI를 논문에서 확인한다. 확인하지 못한 항목은 `확인 필요`.
3. **노트 작성:** `templates/reading-note.md`의 구조로 Word 문서 `reading/<첫저자 성>_<연도>_<핵심어>.docx`를 만든다(`CLAUDE.md`의 "Word 만들기").
   - 결과마다 그 수치나 주장이 실린 패널을 붙인다(예: Fig. 2B). 범위로 뭉뚱그리지 않고, 패널을 특정하지 못하면 `Fig. 2 (패널 확인 필요)`로 쓴다.
   - 저자의 주장과 나의 해석을 나눈다.
   - 원문을 길게 옮기지 않는다. 인용은 꼭 필요한 짧은 구절만 쓴다.
4. **내 연구와의 연결:** `projects/*/status.md`, `plan.md`를 읽고, 이 논문이 내 프로젝트의 어디에 쓰일 수 있는지(방법, 대조군, 비교할 결과, 반대 근거) 적는다. 연결이 약하면 억지로 만들지 않고 "직접 관련 없음"이라고 쓴다. 연결의 각 줄은 논문에 있는 사실과 `해석:`을 나눠 쓴다.
5. **웹 확인 (필요할 때):** 이 논문의 정정(correction)·철회(retraction) 여부나 중요한 후속 연구를 확인하고, 출처(제목, URL, 확인일)를 노트의 "확인 필요" 또는 해당 칸에 남긴다.
6. 관련 프로젝트의 `plan.md` "관련 논문"에 이 노트를 추가할지 사용자에게 묻는다.

## 주의

- 논문에 없는 수치나 결론을 쓰지 않는다.
- 노트는 초안이다. 사용자가 논문을 직접 읽고 고쳐야 한다는 점을 마지막에 알린다.
