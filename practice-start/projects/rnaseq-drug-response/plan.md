# rnaseq-drug-response — 계획

## 연구 질문

drug A는 A549 세포의 어떤 유전자 발현을 바꾸는가?

## 가설

drug A는 p53 경로를 활성화한다. (p53-ko-cell 프로젝트에서 검증)

## 접근 방법

1. A549 세포에 drug A(1 µM) 또는 DMSO를 24시간 처리한다. 각 n=3.
2. 업체에 RNA-seq을 맡긴다 (paired-end).
3. DESeq2로 차등 발현을 분석하고, 경로 분석을 한다.

## 마일스톤과 목표 시기

| 단계 | 목표 시기 | 완료 기준 |
|---|---|---|
| 시퀀싱 데이터 수령 | 2026-11 | 모든 시료 QC 통과 |
| DEG 분석 | 2026-11 | padj < 0.05 유전자 목록 |
| 경로 분석·검증 계획 | 2026-12 | qPCR 검증 대상 유전자 선정 |
